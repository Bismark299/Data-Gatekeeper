POST
https://console.ckgodsway.com/api/data-purchase
Purchase internet data package - automatically debits user balance and creates transaction

Headers
Content-Type	application/json
X-API-Key	your-api-key-here
Request body
networkKey	string (required) - Network identifier: 'YELLO', 'AT_PREMIUM', 'TELECEL', 'AT_BIGTIME'
recipient	string (required) - Phone number to receive data (10 digits starting with 0)
capacity	string (required) - Data amount in GB (e.g., '1', '2', '5')
reference	string (optional, ≤100 chars, [A-Za-z0-9_-:.]) - Your own tracking reference.
Responses
200
Data package purchased successfully
Example response
{
  "success": true,
  "message": "Order placed successfully",
  "data": {
    "network": "MTN",
    "capacity": "1GB",
    "price": 7,
    "recipient": "0201234567",
    "reference": "my-system-tx-9821",
    "status": "PROCESSING",
    "orderDate": "2024-01-15T10: 30: 00Z"
  },
  "balance": {
    "previous": 100,
    "current": 93,
    "deducted": 7
  }
}

}

{
  "success": false,
  "error": "recipient phone number is required"
}
Invalid recipient
{
  "success": false,
  "error": "Recipient must be a valid 10-digit phone number starting with 0"
}
Missing capacity
{
  "success": false,
  "error": "capacity (data amount) is required"
}
Invalid capacity
{
  "success": false,
  "error": "Capacity must be a positive number"
}
Insufficient balance
{
  "success": false,
  "error": "Insufficient balance. Required: ₵7.00, Available: ₵5.00"
}

POST
https://console.ckgodsway.com/api/result-checker-purchase
Purchase one or more exam result checker cards (WASSCE, BECE, etc.).

Headers
Content-Type	application/json
X-API-Key	your-api-key-here
Request body
checkerType	string (required) - Result checker name e.g. 'WASSCE' or 'BECE'. Case-insensitive. Aliases accepted: voucherType, type.
recipient	string (optional) - Phone number to receive the cards via SMS (10 digits starting with 0). Defaults to the API key owner's phone.
quantity	number (optional, default 1, max 30) - Number of checker cards to purchase per request.
reference	string (optional) - Your own tracking reference.
Responses
400
Validation, balance, or stock error
Missing checkerType
{
  "success": false,
  "error": "checkerType is required (e.g. 'WASSCE' or 'BECE'). See /api/external/docs for the supported list."
}
Invalid recipient
{
  "success": false,
  "error": "recipient must be a 10-digit phone number starting with 0 (e.g. 0541234567)"
}
Insufficient balance
{
  "success": false,
  "error": "Insufficient balance. Required: ₵17.50, Available: ₵5.00"
}
Insufficient stock
{
  "success": false,
  "error": "Insufficient checker cards available. Requested: 10, Available: 3"
}
