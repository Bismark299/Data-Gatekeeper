Allowlist Rules

Single domain/IP: Only that host can call your API (most secure)
Security bypass: Allowlisted hosts bypass WordPress security plugins/firewalls (including country blocking)
Wildcards supported: Use *.example.com to allow all subdomains
Server-to-server: Allowlist server IPs or domains (e.g., 192.168.20.5 or myserver.com)
No entry: All API requests are blocked
Protection: Blocks unknown websites/apps from using your API credentials
Important

You must add at least one domain or server to use the API. Without it, every request is denied. This ensures your API credentials only work from trusted systems.

Examples:
• example.com - Allow only example.com (strict)
• *.example.com - Allow all subdomains of example.com
• yoursite.com - Allow your server domain
• 192.168.20.5 - Allow specific server IP (not recommended, use domain instead)
